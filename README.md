# Dot Matrix

A single-screen Flutter countdown timer for mobile.

- True black background for AMOLED displays.
- 6 x 10 dot matrix (60 dots, one dot per minute).
- Neon green on black, monospace typography.
- Tap a dot to start a timer of that many minutes.
- Drag to scrub the preview; pointer-up starts the timer.
- Hold anywhere on screen for 700 ms to cancel.
- Header shows `mm:ss`; hint text adapts to state.
- End state: 8 s eased flash + two chimes, then a 60 s calm "done" state; tap to dismiss.
- Supports app backgrounding/resume and persisted timer restoration.
- Android keeps the screen awake while a timer is active, then applies the burn-in reduction policy: brightness and readout intensity step down, unlit dots fade to black, and the dot grid shifts position; the display is allowed to sleep after the completed-timer state. Play start/end sounds with the `start.ogg`/`end.ogg` assets.

## Development

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

## Sound assets

`assets/sounds/start.ogg` and `assets/sounds/end.ogg` are generated by `tools/gen_sounds.py` (requires `numpy` and `ffmpeg`).

```bash
python3 tools/gen_sounds.py
```

## Platform notes

- Android: requests notification permission at app start and gracefully falls back if exact alarms are denied.
- Android: active timers keep notification permission and post an ongoing timer notification while backgrounded; while backgrounded, the notification countdown is driven by a live chronometer.
- Android: notification and launcher icons use the app's custom dot-grid assets; notification status icons are monochrome.
- Release downloads are per-architecture APKs (`armeabi-v7a`, `arm64-v8a`, `x86_64`) with SHA256 checksums.
- iOS: notification sound uses a bundled `.wav` file.
- True 1-2 Hz idle refresh is requested on supported Android devices; support varies by hardware.
